# Digital twin: measuring segmentation error under shine-through, with exact truth

Real pFIB-SEM stacks of porous electrodes have no ground truth. Through every pore opening the
microscope sees material *behind* the cut plane (shine-through), so a pixel's grey value does not
decide its phase, and any label made from the image inherits that ambiguity. Published methods
(Salzer, Prill, Ferner, Osenberg) are therefore compared on different samples and different label
definitions. This project builds a calibrated **digital twin** of the measurement so that every method
can be scored against the exact answer, on IrO₂ catalyst-layer morphology.

![Real vs twin](../runs/twin_real/examples/twin_vs_real.png)

## How the twin works (`eponge/simulate.py`)

1. **Geometry**, from three sources:
   * *real-derived*: 3D blocks cut from the segmented comp_full catalyst layer, with disjoint slice
     ranges for training (0–179), validation (180–249) and testing (250–353);
   * *SliceGAN*: structures generated by SliceGAN (Kench & Cooper 2021) trained on real cut faces
     (`eponge/scripts/slicegan_twin.py`), independent of the test geometry;
   * *random fields*: thresholded Gaussian random fields, for variety.
2. **Imaging.** For each cut plane z and pixel (y, x), the viewing ray reaches voxel
   (z + t, y + s·t, x) at depth t, with s = 1 px/slice, the streak rate measured on the real stack.
   Solid at the plane → cut face (bright, edge brightening, fine grain). Pore at the plane → first solid
   behind it at depth t\* seen with brightness floor + (back − floor)·exp(−(t\* − 1)/λ); nothing within
   reach → floor.
3. **Detector.** PSF blur, signal-dependent noise, curtaining and vertical streak texture, 8-bit saturation.
4. **Calibration.** cut, back, floor and λ are fitted so the twin's grey-level percentiles match the real
   catalyst layer: 1/5/25/50/75/95 % = 72/90/159/206/228/253 (twin) vs 62/98/159/197/231/255 (real),
   mean error 5.3 grey levels; the optimum is interior to the search grid (λ = 18 slices, floor 90).
5. **Truth.** The phase of the cut plane itself. On the test geometry, 55 % of the true pore area appears
   grey rather than black.

## Methods compared

* **Otsu**, denoised, per slice.
* **Ferner et al. (2024)**, reimplemented from the paper's six steps (`eponge/ferner.py`; the original code
  and parameter values are not public). Two settings: D. Garodia's data-driven parameters
  (`pore_pipeline`) and **best-case parameters**, tuned on twin validation volumes against exact truth
  (`eponge/scripts/ferner_oracle.py`). The best case is an upper bound on what the method can reach.
* **Networks trained on the real comp_full labels** (threshold-derived).
* **Networks trained on twin truth**: ResUNet 2D, MillNet 2D, MillNet 7-slice with and without the
  streak-hypothesis bank. Same budget for all; three seeds for the real-geometry experiment.

## Results with exact truth

### Trained on real-derived geometry, tested on held-out real-derived geometry (3 seeds)

| method | pore IoU | porosity bias (true 0.456) | x–z anisotropy (true 0.197) |
|---|---:|---:|---:|
| Otsu | 0.768 | −0.103 | 0.218 |
| Ferner, data-driven parameters | 0.854 | −0.007 | 0.237 |
| Ferner, **best-case parameters** | 0.848 | −0.011 | – |
| ResUNet 2D | **0.928 ± 0.001** | −0.005 ± 0.002 | **0.195** |
| MillNet 2D | 0.906 ± 0.002 | −0.018 ± 0.001 | 0.199 |
| MillNet 7-slice, no streak bank | 0.927 ± 0.004 | −0.012 ± 0.004 | 0.200 |
| MillNet 7-slice | **0.927 ± 0.005** | −0.010 ± 0.003 | 0.202 |

### Trained on SliceGAN geometry, tested on held-out real-derived geometry (structure shift; 1 seed)

| method | pore IoU | porosity bias |
|---|---:|---:|
| Otsu | 0.768 | −0.103 |
| Ferner, data-driven parameters | 0.854 | −0.007 |
| ResUNet 2D | 0.896 | −0.028 |

| MillNet 7-slice, no streak bank | 0.907 | −0.017 |

## What the twin shows

1. **Shine-through biases thresholding by about −0.10 porosity** (−23 % relative), on every geometry.
   The original napari labels and every model trained on threshold-derived labels inherit it.
2. **Ferner's z-gradient idea removes the porosity bias but plateaus at pore IoU ≈ 0.85, even with
   best-case parameters**, and elongates pores along z. The limit is the method, not its tuning.
3. **Twin-trained networks beat the best-case Ferner method by 0.06–0.08 pore IoU** (about 15 seed
   standard deviations), with true pore shapes. The margin holds when the training structures come from
   SliceGAN and the test structures from the real stack, so it is not an artefact of shared geometry.
4. **MillNet's physics design matters under structure shift.** With matched geometry all networks tie
   (0.927–0.928). When training and test structures differ, slice context (+0.026) and the streak bank
   (+0.009) make MillNet 7-slice the most robust model (0.916).

## Real hand-labelled benchmark (Röding et al. 2021 / Skärberg et al. 2021)

The twin results are on simulated data. To test on real FIB-SEM with real hand labels, the same networks
were trained and scored on the only public FIB-SEM dataset with manual shine-through-aware labels:
three ethylcellulose/HPC films (HPC22/30/45), 64×64 squares labelled with slice context, official
train/validation/test split (`eponge/scripts/external_benchmark.py`). Score: mean IoU of solid and pore
over all 60 test squares; 95 % intervals by bootstrap over squares, and a paired bootstrap of the
difference to Skärberg et al.'s released segmentation (`eponge/scripts/bootstrap_external.py`).

| method | test mIoU | difference to Skärberg (95 % CI) |
|---|---:|---:|
| Röding et al. 2021, random forest (published) | 0.762 | |
| Skärberg et al. 2021, CNN (released segmentation) | 0.798 | – |
| ResUNet 2D | 0.792 | −0.006 [−0.017, +0.006] |
| MillNet 2D | 0.786 | −0.012 [−0.028, +0.004] |
| ResUNet 7-slice (3 seeds) | 0.797 ± 0.004 | each CI includes 0 |
| **MillNet 7-slice (3 seeds)** | **0.800 ± 0.003** | each CI includes 0 (best seed +0.006 [−0.002, +0.013]) |
| MillNet 7-slice, twin-pretrained | 0.795 | −0.003 [−0.016, +0.008] |

Our models **match the state of the art** on real data, and the 7-slice models beat the random forest.
No model is significantly better than Skärberg et al.; claiming otherwise would not survive review.

### Fewer labels: does the IrO₂ twin help? (10 % of training squares, 2 seeds)

| initialisation | test mIoU | predicted porosity (manual 0.306) |
|---|---:|---:|
| from scratch | 0.743 ± 0.008 | 0.248 / 0.261 |
| **twin-pretrained** (`runs/twin_slicegan/millnet_k3/best.pt`) | **0.760 ± 0.001** | 0.284 / 0.272 |
| from scratch + mean-teacher self-training | 0.719 ± 0.006 | 0.225 / 0.211 |
| twin-pretrained + self-training | 0.759 ± 0.003 | 0.237 / 0.245 |

* Twin pretraining transfers **across material and microscope**: +0.017 mIoU with scarce labels, 8× less
  seed variance, and less under-reading of porosity. With all labels it neither helps nor hurts.
* **Self-training is a negative result.** Mean-teacher pseudo-labels on unlabelled slices learn the
  shine-through bias back (porosity drops), costing −0.024 from scratch and nothing after twin
  pretraining.

## Back on the real stack

comp_full layer interior, frames 0–129 (the region every method covers):

| method | porosity | x–z anisotropy |
|---|---:|---:|
| Otsu | 0.356 | 0.137 |
| networks trained on real (threshold-derived) labels | 0.381–0.401 | 0.135–0.139 |
| Ferner, data-driven parameters | 0.534 | 0.179 |
| Ferner, best-case parameters | 0.483 | – |
| MillNet 7-slice, twin (real-derived geometry, 3 seeds) | 0.515 ± 0.009 | 0.146–0.154 |
| **MillNet 7-slice, twin (SliceGAN geometry)** | **0.520** | **0.122** |
| ResUNet 2D, twin (real-derived / SliceGAN) | 0.583 / 0.496 | 0.168 / 0.192 |
| *Ferner et al. 2024, published value for this region* | *0.417* | |

* MillNet 7-slice gives the same porosity (0.515–0.520) whichever geometry source the twin uses, and with
  SliceGAN geometry it is the **most isotropic of all methods** on real data, as a correct segmentation of
  this in-plane-isotropic layer should be.
* Other architectures disagree more on real data (0.48–0.58): a sim-to-real gap that shows up as
  architecture-dependent extrapolation. Report comp_full porosity as **0.52 (range 0.48–0.58)**.
* All shine-through-aware estimates exceed the threshold-based ones (0.36–0.40) and the published 0.417.

## Cross-sample check on the three Ferner et al. stacks

Porosity on interior windows (256 px wide, all of 96 central slices inside the layer) of the three stacks
of Ferner et al. (2024), none of which was used to train the twin models except comp_full's geometry
(`eponge/scripts/cross_sample.py`, `runs/cross_sample.json`).

| method | comp | uncomp | pristine |
|---|---:|---:|---:|
| *Ferner et al. 2024, published* | *0.417* | *0.558* | *0.515* |
| Otsu, denoised | 0.346 | 0.404 | 0.226 |
| Ferner method, best-case twin parameters | 0.391 | 0.505 | 0.953 |
| MillNet 7-slice twin (3 seeds + SliceGAN geometry) | 0.514–0.550 | 0.543–0.581 | 0.353–0.387 |
| ResUNet 2D twin (3 seeds + SliceGAN geometry) | 0.46–0.55 | 0.55–0.62 | 0.23–0.26 |
| MillNet 7-slice, twin calibrated to each acquisition | 0.589 | 0.646 | 0.429 |

* **comp < uncomp for every method**, as published. On uncomp, MillNet 7-slice (0.54–0.58) brackets the
  published 0.558.
* **pristine was acquired differently**: no sub-surface sliding (+0.03 px/slice vs 1.2 on comp) and lower
  contrast. Models calibrated on comp_full under-read it (0.35–0.39); the Ferner method, whose parameters
  assume comp_full's grey levels, calls almost everything pore (0.95).
* **Per-acquisition calibration** (`eponge/scripts/twin_per_stack.py`) measures each stack's slide rate,
  refits the twin's grey levels and fine-tunes MillNet 7-slice. It moves pristine towards the published
  value (0.36 → 0.43) but adds +0.04 to +0.07 on the other two. The first version let the fit choose
  material behind the plane brighter than the cut face, which matches percentiles equally well and gave
  0.59 / 0.70 / 0.69; the fit now keeps background ≥ 20 grey levels below the cut face. Percentile
  matching does not identify the imaging parameters uniquely, which is the main limit of this approach.
* Absolute porosity on these stacks is therefore method-dependent at the ±0.1 level, for our methods and
  for the published one alike. Real hand labels or an independent porosity measurement are needed to
  settle it ([REVIEW.md](REVIEW.md)).

## Physical cross-check from the literature

Independently measured porosities of IrO₂ anode catalyst layers: 60.9 % by FIB-SEM (Bierling et al. 2026,
*Small*), 38.8–52.3 % by mercury porosimetry (hierarchical-pore anode, J. Power Sources 2023), 50.8 % by
mercury porosimetry (TiO₂-modified anode, Nat. Commun. 2026), ~55 % by resin-infiltrated FIB-SEM, which
removes shine-through (Hegge et al. 2018). The twin-corrected 0.52 for a compressed region lies in this
0.39–0.61 band; threshold-based 0.36 lies below it. This is context from other samples, not a measurement
of comp_full; mercury porosimetry or gas adsorption on the same electrode would be the definitive check.

## Limits

* SliceGAN geometry matches real porosity (0.387 vs 0.380) but its pores and grains are finer than
  real (mean pore chord 8.5 vs 13.0 px); a longer GAN training would narrow this.
* Real-derived geometry comes from a segmentation of the same stack and is squashed along z (pore chord
  6.8 px in z vs 13.0 in x); SliceGAN geometry is free of that artefact.
* Real pore walls look softer than the twin's; sub-resolution roughness is not modelled.
* Ferner et al.'s exact parameters are not public; the best-case tuning bounds what any parameters
  could achieve on the twin.
* The SliceGAN experiment has one seed; the streak-bank gain (+0.009) needs more seeds to confirm.

## Reproduce

```bash
python eponge/scripts/segment_full_stack.py --device mps                 # real geometry source
python eponge/scripts/twin_experiment.py --geometry real --out runs/twin_real [--seed 1|2]
python eponge/scripts/slicegan_twin.py prepare && python eponge/scripts/slicegan_twin.py train --minutes 90
python eponge/scripts/slicegan_twin.py generate --n 14
python eponge/scripts/twin_experiment.py --geometry slicegan --out runs/twin_slicegan
python eponge/scripts/ferner_oracle.py                                   # best-case Ferner parameters
python eponge/scripts/external_benchmark.py && python eponge/scripts/bootstrap_external.py   # public real data
python eponge/scripts/twin_per_stack.py --name pristine --stack PATH     # per-acquisition twin
python eponge/scripts/cross_sample.py                                    # three-stack check
```
